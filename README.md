# SRE Brain

GitHub Pages documentation for **Automon + GKE + Monarch**.

## Publish with GitHub Pages

1. Upload `index.html` and `style.css` to the repository root.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Select the `main` branch and `/ (root)`.
5. Save and wait for GitHub Pages to deploy.

The resulting site will be available at:

`https://<github-username>.github.io/<repository-name>/`

## Files

- `index.html` — the complete SRE Brain documentation page.
- `style.css` — responsive documentation styling.
- `README.md` — repository instructions.

## Scope

The document distinguishes documented Google Cloud behavior from organization-specific Automon/Monarch implementation details. Internal router names, APIs, and service topology should be replaced with the actual internal documentation when available.
